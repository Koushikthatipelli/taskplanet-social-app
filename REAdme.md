# TaskPlanet

A social media web application built using the MERN Stack.

## Features

- User Authentication
- JWT Login System
- Create Posts
- View Feed
- Like Posts
- Comment on Posts
- Responsive UI
- MongoDB Atlas Database

## Tech Stack

Frontend:
- React.js
- Material UI
- Axios

Backend:
- Node.js
- Express.js
- MongoDB Atlas
- JWT
- Bcrypt

## Deployment

Frontend: Vercel
Backend: Render
Database: MongoDB Atlas
